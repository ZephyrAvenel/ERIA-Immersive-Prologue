# Clarification augmentée

Quatrième atelier augmenté de l’INE.

- ID runtime : `clarification-augmentee`
- Slug : `clarification-augmentee`
- Route : `/ateliers/clarification-augmentee/`
- Format : `ine-workshop-pack`
- Statut : contenu éditorial final
- Structure : 7 mouvements, 26 étapes
- Couverture : finale, `assets/images/00-couverture-clarification-augmentee.png`
- Promesse éditoriale : clarifier une œuvre sans l’appauvrir, en distinguant ce qui demande réellement d’être rendu plus lisible de ce qui doit rester complexe, ouvert ou irréductible.
- Règle centrale : clarifier n’est pas simplifier ; c’est rendre plus visible ce qui compte sans effacer ce qui doit rester vivant.
- Règle IA : l’IA aide à faire apparaître des écarts, des relations et des options ; l’humain décide ce qui compte, ce qui doit rester complexe, ce qui peut disparaître et quand s’arrêter.

Ce pack contient le parcours éditorial complet de l’atelier « Clarification augmentée ».
